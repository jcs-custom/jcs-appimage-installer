# JCS Office Staff Auto Installer

Purpose:
Automatic installation package for JCS Custom Lubuntu ISO.

Target:
Office Staff / Business Users

Architecture:
x86_64

Base:
Lubuntu 26.04

Installation Methods:
- Flatpak
- DEB
- Snap
- AppImage

Project Goal:
Create a portable Office Staff application installer that can be reused
for future Lubuntu releases.
